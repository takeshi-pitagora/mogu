## このバージョンの新機能（日本語・App Store に出る文）

自分の記録を見られるようになりました。

・「探検手帳」を追加しました。これまでの記録・番付・もらったいいね・見つけたお店・コインのもらい方を、1冊にまとめて見られます
・プロフィールの写真に「dig」が付きました。ほかの人からもらったいいねの数で上がります
・プロフィールに「記録」を追加しました。月ごとに、新しく見つけたお店・よく行くエリア・夜と昼のひとり平均が、レシートの形で出ます。その月のまとめを画像にして残せます
・ほかの人のプロフィールで「あなたとの相性」が見られるようになりました
・お店が10人・50人・100人に保存されたときと、登録がしっかりそろったときに、コインが増えるようになりました

## 審査メモ（App Review Information → Notes）

前のバージョン 1.3 からの差分です。

1. アプリ内ポイント「モグコイン」の表示
   - 1.3 まではサーバーに貯めるだけでしたが、このバージョンから
     「探検手帳」の中で数を見られるようにしました。
   - **購入・換金・譲渡はできません。** 買う・替える・渡すための画面も導線もありません。
     アプリ内課金（IAP）も使っていません。投稿してくれた人の記録を、本人だけが
     見られるようにしたものです。画面にも「コインも dig も、お金や商品には換えられません」
     と明記しています（探検手帳の「もらい方」のページ）。
   - 取り消し：投稿が削除されたとき・登録が取り消されたとき・規約違反のときは、
     記録を消さずに「取消」に変え、理由を本人に見せます。
2. 番付（ランキング）
   - 確定したコインの多い順に上位100人を出します。
   - 設定の「ランキングに名前を出す」をオフにすると名前は出ません（コインは貯まり続けます）。
     投稿を停止されている人も出ません。
   - 出るのは、ニックネーム・アイコン・@ID・dig・コインの数だけです。
3. dig
   - ほかの人からもらった「いいね」（見つけたお店が保存された／自分の写真やタグへの＋1）の
     累計で上がる数字です。本人のいいねと、登録から7日未満のアカウントのいいねは数えません。
4. 月のまとめの画像
   - 端末の中で画像を作り、保存または共有シートに渡すだけです。
     サーバーには送っていません。
